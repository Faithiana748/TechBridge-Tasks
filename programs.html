Learn by doing, not just by reading

TechBridge programs are practical. You build real skills through hands-on, project-based work in a 30-day internship. Pick the program that matches where you want to go.

Data Analytics

Working with data and extracting insights.

This program introduces you to practical data analysis. You learn how to take raw data, prepare it, analyse it and present what it means for a business.

Apply for TechBridge Internship

Skills you will develop

  • Spreadsheet analysis

    Organise, calculate and explore data in spreadsheets.

  • Data cleaning

    Fix errors and gaps so your data can be trusted.

  • SQL

    Ask questions of data using the language of databases.

  • Data visualization

    Turn numbers into charts that people can understand quickly.

  • Business-focused analysis

    Connect your findings to the decisions a business has to make.

Web Development

Designing and building websites and web applications.

This program introduces you to practical website development. You learn the core languages of the web and use them to build projects you can show to others.

Apply for TechBridge Internship

Skills you will develop

  • HTML

    Structure the content of a web page.

  • CSS

    Style pages and make them work on any screen size.

  • JavaScript

    Add behaviour and interaction to your pages.

  • Git/GitHub

    Save your work, track changes and publish projects.

  • Building web projects

    Bring the skills together by building complete projects.

Which program is right for you?

Both programs are practical and project-based. The difference is what you spend your time making.
