Your 8 tasks, in order

Work through the tasks from top to bottom. Open Task details on any card to see what you are expected to build.

  1. Day 1
    Task 1 Beginner

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS.

    Task details
    You will build
    A responsive homepage that explains what TechBridge is, what it offers, and how to apply.
    How it fits
    The starting point. Every later task builds on this website.
  2. Day 4
    Task 2 Beginner → Intermediate

    Build the TechBridge Programs Experience

    Create a Programs experience that presents TechBridge's available learning programs.

    Task details
    You will build
    A Programs page that explains Data Analytics and Web Development and the skills in each.
    How it fits
    Extends your Task 1 website with a second page.
  3. Day 8
    Task 3 Beginner → Intermediate

    Build the Internship Tasks Experience

    Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

    Task details
    You will build
    A page that shows all 8 tasks with their days, descriptions and the progression between them.
    How it fits
    Adds a third page and connects Home, Programs and Internship Tasks.
  4. Day 11
    Task 4 Beginner → Intermediate

    Build an Interactive Internship Roadmap

    Use JavaScript to allow visitors to switch between the Data Analytics and Web Development internship tracks.

    Task details
    You will build
    An interactive roadmap where a visitor can switch between the two internship tracks without refreshing the page.
    How it fits
    The first task that uses JavaScript. Try the roadmap.
  5. Day 15
    Task 5 Intermediate

    Build the Intern Registration Experience

    Create a professional registration/onboarding interface for TechBridge interns.

    Task details
    You will build
    A professional registration and onboarding interface for new TechBridge interns.
    How it fits
    Starts the intern-facing side of the platform.
  6. Day 19
    Task 6 Intermediate

    Build the Task Submission System

    Create an interface through which interns can prepare and submit their task work.

    Task details
    You will build
    An interface where interns prepare and submit their task work.
    How it fits
    Gives interns a place to hand in what they have built.
  7. Day 22
    Task 7 Intermediate

    Build the Intern Dashboard

    Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

    Task details
    You will build
    A dashboard that shows an intern's profile, progress, tasks and submissions in one place.
    How it fits
    Brings the earlier interfaces together into one view.
  8. Day 26
    Task 8 Intermediate

    Build the Complete TechBridge Internship Platform

    Combine the different components created during the internship into a complete TechBridge platform.

    Task details
    You will build
    A complete TechBridge platform that combines the components from the earlier tasks.
    How it fits
    The final task. It pulls the whole internship together.
