    Technology Explorer

    How the dashboard talks to the backend

    The tasks on this page are not written in the HTML or in the JavaScript. The dashboard asks a Node.js and Express server for them with fetch(), and the server answers with JSON.

    1. Intern Dashboard
    2. fetch() sends a request
    3. REST API (Express)
    4. reads and updates
    5. Task data (tasks.json)
    6. JSON response goes back to the dashboard

    API endpoints

    MethodEndpointWhat it does
    GET /api/tasks Returns all 8 tasks as a JSON array. The dashboard uses it to build the task cards and the progress numbers.
    GET /api/tasks/:id Returns one task, for example /api/tasks/3. The View Task window uses it. An unknown id returns a 404 error.
    PUT /api/tasks/:id Updates a task's status. The body is { "status": "completed" }. The Mark as Completed button uses it.
    GET /api/health Extra. Replies { "status": "ok" } so the dashboard can show the Backend Status.
    POST /api/reset Extra. Puts the tasks back to their starting state. The Reset progress button uses it.

    GET Retrieve

    Used to get information. GET /api/tasks means: give me the tasks.

    PUT Update

    Used to change existing information. PUT /api/tasks/3 means: update Task 3.

    Run the backend on your computer

    1. Install Node.js, then open a terminal in the backend folder.
    2. Run npm install once to install Express.
    3. Run npm start. The server starts at http://localhost:3000.
    4. Open http://localhost:3000/dashboard.html. Backend Status shows Connected.
